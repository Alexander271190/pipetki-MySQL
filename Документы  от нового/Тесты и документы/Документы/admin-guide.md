## 1. Введение

### 1.1. Кому это руководство

Администратор — пользователь с ролью admin (встроенной или кастомной с флагом полного доступа). Администратор имеет полный доступ ко всем функциям системы, включая:

- управление пользователями и ролями;
- настройку полей формы, отделов, типов оборудования;
- настройку политики паролей;
- управление принтерами и штрихкодами;
- просмотр журналов (аудит + ошибки);
- сброс данных.

### 1.2. Принципы безопасности

Администратор видит всё, но есть встроенные защиты:

- нельзя удалить встроенного admin;
- нельзя понизить последнего администратора;
- нельзя удалить себя из системы;
- логин admin нельзя менять;
- критичные настройки (пароли, impersonation) — только для админов.

### 1.3. Что нельзя делать никому (даже админу)

- изменить системные роли (user, senior_lab, admin);
- удалить последнего админа;
- восстановить удалённые данные без бэкапа.

## 2. Первый вход

### 2.1. Установка пароля администратора

При первой установке системы создаётся учётная запись admin без пароля.

1. Откройте экран входа.
2. Введите логин admin, поле «Пароль» оставьте пустым.
3. Нажмите «Войти».
4. Система попросит установить пароль.
5. Введите новый пароль (соответствующий политике) → «Установить».

> 🖼️ **Скриншот 2.1 — Первый вход: установка пароля**
> Снять: модалку «Установка пароля администратора» с тремя полями и списком требований.

### 2.2. Что сразу проверить после первого входа

- Настройки → Пользователи — создать хотя бы одного обычного пользователя.
- Настройки → Отделы — проверить список (8 дефолтных).
- Настройки → Типы оборудования — проверить префиксы и МПИ.
- Настройки → Политика паролей — при необходимости ужесточить.
- Настройки → Печать документов — настроить шапку и поля актов.
- Настройки → Принтеры — добавить хотя бы один принтер.

## 3. Оборудование и данные

### 3.1. Поля формы

Настройки → Поля формы. Раздел определяет, какие поля показываются в форме создания/редактирования оборудования.

> 🖼️ **Скриншот 3.1 — Поля формы**
> Снять: таблицу полей с колонками «Порядок», «Название», «Тип», «Обязательно», «Активно», «Список значений», «Действия».

Колонки:

- **Порядок** — стрелки для перестановки;
- **Название** — отображаемое имя поля;
- **Тип** — текст / число / дата / список / текстовая область;
- **Обязательно** — чекбокс;
- **Активно** — чекбокс (включить/отключить поле);
- **Список значений** — для типа «Список», значения через перевод строки;
- **Действия** — удалить поле.

Особенности:

- системные поля (id, department, equipmentType, result, active) — тип заблокирован;
- удаление поля с данными → запрос подтверждения. При подтверждении данные стираются у всех приборов;
- кнопка «Отображение в списках» — настраивает, какие поля видны в массовых операциях. Первые 2 поля (обычно ID и Модель) выводятся крупно, остальные — мелким шрифтом.

### 3.2. Отделы

Настройки → Отделы.

> 🖼️ **Скриншот 3.2 — Отделы**
> Снять: таблицу отделов с колонками «Активно», «Название», «Действия».

Что можно делать:

- **Добавить** отдел (поле внизу + «Добавить»);
- **Переименовать** — при сохранении все приборы и пользователи переедут в новый отдел;
- **Отключить** (снять «Активно») — отдел останется, но не будет доступен для выбора;
- **Удалить** — только если отдел не используется ни одним прибором (иначе ошибка).

Важно: при удалении используемого отдела — сначала переведите приборы в другой отдел.

### 3.3. Фильтры

Настройки → Фильтры. Определяет фильтры на главной странице.

> 🖼️ **Скриншот 3.3 — Фильтры**
> Снять: таблицу фильтров с колонками «Порядок», «Активно», «Название», «Тип», «Источник».

Типы фильтров:

- **Текст** — свободный ввод;
- **Список** — выпадающий список;
- **Период дат** — выбор периода (сегодня/вчера/неделя/месяц/произвольный).

Источники опций (для типа «Список»):

- departments — отделы;
- status_list — статусы (в норме/скоро/просрочен/на поверке...);
- active_list — активность (в работе / не используется);
- equipment_type_list — типы оборудования.

### 3.4. Печать документов

Настройки → Печать документов. Управление документами для экспорта.

> 🖼️ **Скриншот 3.4.1 — Официальный бланк (шапка)**
> Снять: блок «Официальный бланк» с чекбоксом «Включить шапку», полем «Текст шапки» и выпадающим списком «Выравнивание».

Шапка документов:

- чекбокс «Включить шапку»;
- текст шапки — многострочный (первая строка жирная 12pt, остальные 10pt);
- выравнивание — по центру / слева / справа.

Шапка выводится сверху всех документов: акт отправки, акт возврата, реестр, история, аудит.

> 🖼️ **Скриншот 3.4.2 — Вкладки документов**
> Снять: вкладки «Печать реестра», «Печать акта отправки», «Печать акта возврата», «Печать истории поверок» с настройками одной из них (чекбокс включения + список полей).

Для каждого документа: чекбокс — включить/отключить печать; список полей — какие колонки выводить.

Поля:

- **Реестр**: ID, серийный, производитель, модель, тип, объём, отдел, дата поверки, следующая, МПИ, дней, ответственный, место, статус, свидетельство, примечание + кастомные;
- **Акт отправки**: ID, модель, производитель, серийный, объём, отдел, ответственный, место, свидетельство, примечание;
- **Акт возврата**: ID, модель, производитель, серийный, объём, отдел, ответственный, свидетельство, результат, примечание;
- **История**: дата, свидетельство, результат, организация, примечание.

### 3.5. Типы оборудования

Настройки → Типы оборудования.

> 🖼️ **Скриншот 3.5 — Типы оборудования**
> Снять: таблицу типов с колонками «Порядок», «Название», «Префикс», «МПИ», «Место поверки», «Замена».

Настройки типа:

| Поле | Описание |
|---|---|
| Название | Отображается в формах и фильтрах |
| Префикс | Буквенный код для ID (1–10 символов, A-Z, 0-9). Уникальный |
| МПИ | Межповерочный интервал по умолчанию (1–120 мес.) |
| Место поверки | Внешняя (отправка в ЦСМ) / На месте (внутренняя) |
| Замена | Разрешить замену со склада при отправке |
| Действия | Удалить (если не используется) |

Важно:

- префиксы уникальны — нельзя два типа с префиксом P;
- удалить используемый тип нельзя — сначала переведите приборы (смените тип);
- смена типа прибора → ID автоматически перегенерируется (P-001 → A-001), история переедет.

Дефолтные типы (при первом запуске): Пипетка (P), Анализатор (A), Термометр (T), Весы (S), Фотометр (F), Микроскоп (M).

### 3.6. Шаблоны вида

Настройки → Шаблоны вида. Шаблоны для быстрого переключения видимых колонок у пользователей.

> 🖼️ **Скриншот 3.6 — Шаблоны вида**
> Снять: таблицу шаблонов с колонками «Название», «По умолчанию», «Действия».

Что можно:

- создать шаблон (выбрать поля);
- назначить пользователю;
- сделать «По умолчанию» (для новых пользователей без своих настроек);
- удалить.

Применение: Настройки → Пользователи → выбрать пользователя → «Настроить видимые поля» → «Шаблон вида» → выбрать → «Применить».

### 3.7. Общие настройки оборудования

Настройки → Общие настройки. Лимиты и ограничения.

> 🖼️ **Скриншот 3.7 — Общие настройки оборудования**
> Снять: форму с четырьмя полями (макс. строк в партии, макс. единиц в массовой операции, макс. длина модели, макс. длина серийного номера).

| Поле | По умолчанию | Описание |
|---|---|---|
| Максимум строк в партии | 100 | Сколько строк можно добавить в «Партию» |
| Максимум единиц в массовой операции | 100 | Лимит на отправку/возврат/удаление |
| Макс. длина модели | 255 | Ограничение на длину модели |
| Макс. длина серийного | 255 | Ограничение на длину серийного |

### 3.8. Таблица и отображение

Настройки → Таблица и отображение.

> 🖼️ **Скриншот 3.8 — Таблица и отображение**
> Снять: форму с чекбоксами размеров страницы, дефолтным размером и плотностью таблицы.

Настройки:

- **Размеры страницы** — какие размеры доступны (50, 100, 200, 500, 1000);
- **Размер по умолчанию** — начальное значение для новых пользователей;
- **Плотность таблицы**: компактная (меньше отступы) / обычная (стандарт) / свободная (больше воздуха).

## 4. Пользователи и роли

### 4.1. Список пользователей

Настройки → Пользователи.

> 🖼️ **Скриншот 4.1 — Список пользователей**
> Снять: таблицу с колонками «Логин», «ФИО», «Должность», «Отдел», «Роль», «Права» и кнопкой ⋮.

Колонки: Логин (уникальный), ФИО, Должность + пометка «(и.о.)» если применимо, Отдел, Роль (название), Права (количество прав или «все» для админа).

### 4.2. Создание пользователя

Кнопка «Добавить пользователя» → заполните:

> 🖼️ **Скриншот 4.2 — Модалка создания пользователя**
> Снять: модалку с полями «Логин», «ФИО», «Должность», «Отдел», «Роль», «Строк на странице», блоком «Права доступа» (пресеты + чекбоксы), «Показывать только свой отдел», «И.о.».

Обязательные поля: Логин (уникальный, проверяется автоматически), ФИО, Должность.

Опциональные: Отдел (если пользователь должен быть привязан к отделу), Роль (по умолчанию «Пользователь»), Строк на странице (личное переопределение).

Права доступа:

- пресеты (Очистить / Пользователь / Ст. лаборант / Все права / свои);
- группы прав — чекбоксы (оборудование, поверки, данные, штрихкоды, администрирование, общие);
- дополнительные права — добавляются к правам роли.

Ограничения:

- «Показывать только свой отдел» — видит только приборы своего отдела;
- «И.о.» — исполняющий обязанности, работает от имени другого.

### 4.3. Разовый пароль

После создания пользователя открывается модалка с разовым паролем.

> 🖼️ **Скриншот 4.3 — Модалка разового пароля**
> Снять: модалку с логином, ФИО, паролем (моноширинным) и кнопкой «Скопировать».

Что делать:

1. Скопировать пароль (кнопка «Скопировать»).
2. Сообщить пользователю.
3. Пользователь войдёт и сразу сменит пароль на свой.

Пароль генерируется автоматически — 12 символов, буквы + цифры + спецсимволы.

### 4.4. Редактирование пользователя

Из списка — ⋮ → «Редактировать».

Что можно менять: ФИО, должность, отдел; роль (если есть права); права (чекбоксы); «Показывать только свой отдел»; и.о. (за кого); логин — только администратор, кроме built-in admin.

> 🖼️ **Скриншот 4.4 — Модалка редактирования с активным полем «Логин»**
> Снять: модалку редактирования, где поле «Логин» активно (не серое).

Правила:

- admin — логин менять нельзя;
- обычный пользователь — админ может менять;
- обычный пользователь — сам себе логин менять не может.

### 4.5. Сброс пароля

⋮ → «Сбросить пароль» → подтверждение → модалка с новым разовым паролем.

При следующем входе пользователь обязан сменить пароль.

### 4.6. Удаление пользователя

⋮ → «Удалить» → подтверждение.

Нельзя удалить: себя, встроенного admin, последнего администратора.

При удалении: все его и.о. (кого он замещал) сбрасываются; блокировки, которые он держал, освобождаются.

### 4.7. Роли

Настройки → Роли.

> 🖼️ **Скриншот 4.7 — Список ролей**
> Снять: таблицу ролей с колонками «Название», «Код», «Админ», «Права», «Действия».

Системные роли (изменить нельзя):

- Пользователь (user) — 3 права;
- Ст. лаборант (senior_lab) — 12 прав;
- Администратор (admin) — все права.

Кастомные роли — можно создавать/редактировать/удалять.

Создание роли:

1. «Добавить роль».
2. Название.
3. Чекбокс «Дать полные права администратора» (если да — права игнорируются, роль становится админской).
4. Чекбоксы прав.
5. Сохранить.

> 🖼️ **Скриншот 4.7.2 — Модалка создания роли**
> Снять: модалку с полем «Название роли», чекбоксом «Дать полные права администратора» и группами прав.

Удалить роль можно, только если она не назначена ни одному пользователю.

### 4.8. Пресеты прав

Настройки → Пользователи → Редактировать → блок «Мои пресеты».

Можно сохранить набор прав под именем и применять одной кнопкой.

> 🖼️ **Скриншот 4.8 — Блок «Мои пресеты»**
> Снять: блок с кнопками пресетов (Пользователь, Ст. лаборант, Все права) и кнопкой «Сохранить текущие как пресет».

### 4.9. Настройка видимых полей

Настройки → Пользователи → ⋮ → «Настроить видимые поля».

> 🖼️ **Скриншот 4.9 — Модалка настройки полей**
> Снять: модалку с двумя вкладками «Поля формы» и «Документы для печати», чекбоксами полей и блоком «Скопировать вид с другого пользователя».

Вкладка «Поля формы»:

- чекбоксы активных полей;
- виртуальные колонки (Следующая поверка, Статус);
- «Скопировать вид с другого пользователя» — подтянуть настройки;
- «Шаблон вида» — применить шаблон;
- «Применить ко всем пользователям» — массово (только тем, у кого нет своих настроек).

Вкладка «Документы для печати»:

- чекбокс «Использовать индивидуальные настройки печати»;
- для каждого документа — включить/отключить + поля.

### 4.10. И.о. (исполняющий обязанности)

Что это: пользователь работает от имени другого (например, зав. отделом ушёл в отпуск, его замещает лаборант).

Настройка:

1. Редактировать пользователя.
2. Чекбокс «Исполняющий обязанности (и.о.)».
3. Выбрать, за кого (из списка активных пользователей).
4. Сохранить.

Что видит и.о.: оборудование отдела основного; работает под ФИО основного (в шапке — «(и.о. за Иванов И.И.)»); права — от роли основного.

### 4.11. Вход под пользователем (impersonation)

Что это: админ может «войти» под другим пользователем, чтобы воспроизвести баг или помочь.

Из списка пользователей: ⋮ → «Войти как этот пользователь».

В шапке: кнопка «← Вернуться» — возврат к своей учётной записи.

> 🖼️ **Скриншот 4.11 — Шапка в режиме impersonation**
> Снять: шапку с ФИО целевого пользователя и кнопкой «← Вернуться» (жёлтая или выделенная).

Режимы (настраиваются в «Безопасность»):

- Отключено — никто не может;
- Только встроенный admin — только admin;
- Все администраторы — любой с полными правами (по умолчанию).

## 5. Безопасность

### 5.1. Политика паролей

Настройки → Политика паролей.

> 🖼️ **Скриншот 5.1 — Политика паролей**
> Снять: форму с полями «Мин. длина», «Макс. длина», чекбоксами требований (строчная, заглавная, цифра, спецсимвол, без пробелов).

Настройки:

- мин. длина — от 6 до 128 (по умолчанию 8);
- макс. длина — от 8 до 128 (по умолчанию 64);
- требовать строчную — да/нет;
- требовать заглавную — да/нет;
- требовать цифру — да/нет;
- требовать спецсимвол — да/нет;
- запретить пробелы — да/нет.

Применение: мгновенно после сохранения. При следующей смене пароля новые требования уже действуют.

### 5.2. Уведомления (напоминания)

Настройки → Уведомления.

> 🖼️ **Скриншот 5.2 — Уведомления**
> Снять: форму с чекбоксом «Показывать напоминания» и списком ролей.

Настройки:

- Показывать напоминания — глобально вкл/выкл;
- Для каких ролей — чекбоксы (Пользователь, Ст. лаборант, Администратор).

Если выключено — напоминания не показываются никому.

### 5.3. Вход под пользователем

Настройки → Вход под пользователем.

> 🖼️ **Скриншот 5.3 — Вход под пользователем**
> Снять: форму с тремя радиокнопками (Отключено / Только встроенный admin / Все администраторы).

Режимы:

- Отключено — impersonation недоступен;
- Только встроенный admin — только admin может входить под другими;
- Все администраторы (по умолчанию) — любой с полными правами.

## 6. Печать и штрихкоды

### 6.1. Принтеры этикеток

Настройки → Принтеры этикеток.

> 🖼️ **Скриншот 6.1 — Список принтеров**
> Снять: таблицу принтеров с колонками «Название», «Режим», «Отдел», «IP», «Размер», «Вкл», «По ум.», «Действия».

Режимы принтера:

- **PDF (A4)** — файл A4 (универсальный);
- **PDF 58×40** — файл под этикеточный принтер;
- **Zebra IP** — отправка по сети (IP + порт, по умолчанию 9100);
- **Zebra агент** — отправка через локальный агент (порт 9200).

Настройки: Название (для отображения в списке), Режим (один из 4), Отдел (для какого отдела, пусто = глобальный), IP (для Zebra IP), Порт (обычно 9100), Размер (58×40 / 40×25 / 100×50), Вкл (активен/нет), По ум. (дефолтный для отдела; если глобальный — для всех).

Проверка связи: ⋮ → «Проверить связь» (для Zebra IP) — TCP-подключение на порт.

### 6.2. Штрихкоды

Настройки → Штрихкоды.

> 🖼️ **Скриншот 6.2 — Настройки штрихкодов**
> Снять: форму с полями «Размер», «Тип ШК», «Копий», «Макс. длина», чекбоксом «Fallback на PDF», выпадающими «Шрифт» и «Порт агента», списком «Поля на этикетке».

| Поле | Описание |
|---|---|
| Размер | 58×40 / 40×25 / 100×50 мм |
| Тип ШК | Code-128 / QR |
| Копий | По умолчанию (1–50) |
| Макс. длина | 8–255 символов (обрезает авто-ШК) |
| Fallback на PDF | Если принтер недоступен — скачать PDF |
| Шрифт | DejaVu / PT Sans / Roboto / Roboto Condensed / Open Sans |
| Порт агента | 9200 (для Zebra агент) |
| Поля на этикетке | Чекбоксы: ID, Модель, Серийный, Инв. номер, Отдел, Ответственный |

Важно: «Макс. длина» применяется мгновенно при создании прибора — если поставить 20, ШК обрежется до 20.

Рекомендация: 3–4 поля на этикетке (больше не влезет на 58×40).

## 7. Справка

### 7.1. Управление разделами

Настройки → Справка.

> 🖼️ **Скриншот 7.1 — Управление справкой**
> Снять: таблицу разделов с колонками «Название», «Файл», «Права доступа», «Показ», «Действия» и кнопками «Добавить раздел», «Применить права из коробки», «Сбросить к заводской».

Кнопки:

- **Добавить раздел** — загрузить файл (.pdf, .docx, .doc) + название + права;
- **Применить права из коробки** — проставить дефолтные права (например, «Добавление партии» → «Добавление оборудования»);
- **Сбросить к заводской** — восстановить дефолтные разделы.

### 7.2. Загрузка раздела

«Добавить раздел»:

1. Название — отображается в списке пользователя.
2. Файл — .pdf / .docx / .doc (максимум 20 МБ).
3. Права доступа — кто увидит (если пусто — все).
4. Сохранить.

> 🖼️ **Скриншот 7.2 — Модалка загрузки раздела**
> Снять: модалку с полями «Название», «Документ», «Права доступа» (мультиселект) и кнопкой «Сохранить».

Права доступа: мультиселект с чекбоксами. Если ничего не выбрано — раздел видят все.

### 7.3. Если файл пропал

В таблице разделов есть колонка «Файл». Если файл пропал с сервера — появится красная надпись «ОТСУТСТВУЕТ». Загрузите файл заново.

> 🖼️ **Скриншот 8 — Общие настройки**

```bash
docker exec -i pipette_new_db mysql -u root -p<ПАРОЛЬ> pipette < backup_20251115.sql
```

- audit_log — удаляется через 365 дней (по AUDIT_LOG_RETENTION_DAYS);

## 11. Частые проблемы

**«Не могу удалить отдел»** — отдел используется приборами. Переведите их в другой отдел, потом удаляйте.

**«Не могу удалить тип оборудования»** — тип используется приборами. Смените им тип, потом удаляйте.

**«Логин администратора менять нельзя»** — это защита встроенного admin, чтобы никто случайно не потерял доступ к системе.

**«Принтер не отвечает»**:

1. Проверьте IP/порт (⋮ → Проверить связь).
2. Проверьте, включён ли принтер.
3. Проверьте сеть (ping).
4. Если не критично — настройте Fallback на PDF (файл будет скачиваться вместо отправки).

**«Импорт не распознаёт колонки»** — проверьте заголовки, они должны совпадать со стандартными. Полный список — в import.js::HEADER_MAP.

**Где смотреть логи**:

```bash
docker logs pipette_new_app --tail 100
docker logs pipette_new_db --tail 50
```

**Как сбросить пароль админа (если потерян)** — через БД:

```sql
UPDATE users SET password = '', must_set_password = 1 WHERE login = 'admin';
```

После этого войти под admin с пустым паролем — система попросит установить новый.
