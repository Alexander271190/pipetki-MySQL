## Соглашение по именам скриншотов

Формат: `<раздел>-<номер>-<slug>.png`, например `02-01-login.png` — скриншот 2.1 из руководства пользователя.

Скриншоты лежат в `screenshots/` каждого документа. При обновлении UI — заменить PNG с тем же именем и пересобрать.
