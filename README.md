# 🔬 Система учёта оборудования КДЛ

Веб-приложение для учёта лабораторного оборудования (пипеток, анализаторов, термометров и др.) и контроля сроков их поверки. Разработано для Клинико-диагностической лаборатории.

---

## 📋 Возможности

### Учёт оборудования
- Добавление, редактирование, удаление единиц оборудования
- Автоматическая генерация внутренних номеров по типу и префиксу (например, `P-001`, `PH-003`)
- Разделение по типам: пипетки, анализаторы, термометры, весы, фотометры + произвольные
- Отслеживание серийных номеров, производителей, моделей, объёмов

### Поверки
- История поверок по каждой единице
- Справочник поверяющих организаций (по умолчанию ФБУ «Красноярский ЦСМ»)
- Результаты: Годен / Брак / В процессе
- Автоматический расчёт даты следующей поверки по МПИ
- Статусы: В норме / Скоро поверка / Просрочена / На поверке / Брак / В процессе

### Массовые операции
- 📦 Массовая отправка на поверку (только пипетки)
- 📥 Массовый возврат с поверки (одно свидетельство на всех или индивидуально)
- 🖨️ Печать акта отправки на поверку
- ✅ Массовые чекбоксы с фильтрацией

### Импорт / экспорт
- Импорт из Excel (`.xlsx`, `.xls`), CSV, JSON
- Автоматическое распознавание заголовков на русском и английском
- Автогенерация ID при импорте, если колонка «ID» отсутствует
- Экспорт в CSV (Excel) и PDF (печать)
- Настраиваемый набор экспортируемых полей

### Настройки (только админ)
- Управление полями формы (тип, порядок, обязательность)
- Управление отделами
- Управление фильтрами (статусы, отделы, типы, произвольные периоды дат)
- Управление типами оборудования (иконка, префикс для авто-ID)
- Управление пользователями и правами
- Журнал действий (аудит)
- Сброс всех данных

### Прочее
- Напоминания о приближающихся поверках (раз в день)
- Авто-ID при создании новой единицы
- Impersonate — вход под другим пользователем (только админ)
- Адаптивный интерфейс (работает на телефоне)
