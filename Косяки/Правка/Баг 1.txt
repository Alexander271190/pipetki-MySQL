TASK-2025-003: Переход style.css на CSS-переменные
─────────────────────────────────────────────────
Приоритет: Низкий
Когда:    Когда будет время и желание
Время:    1–2 часа
Что:      
  - Добавить :root с переменными --bg, --text, --card и т.д.
  - Постепенно (не за раз) заменить хардкод на var(--xxx)
  - Упростить тёмную тему — вместо html[data-theme=dark] .card {...}
    использовать html[data-theme=dark] { --card: ... }
Плюсы:
  - Легче менять цвета (1 место вместо 200)
  - Меньше кода для тёмной темы
  - Соответствие стандартам
Минусы:
  - Риск сломать стили
  - Время
  - Для 3-6 пользователей выгода незначительная





TASK-2025-004: HTTPS для работы камеры
──────────────────────────────────────
Приоритет: Средний
Когда:    Если планируется использование сканера камерой
Причина:  Браузеры блокируют getUserMedia на HTTP
Что:      
  - Получить SSL-сертификат (Let's Encrypt)
  - Настроить HTTPS в nginx (reverse-proxy)
  - Или в самом Node.js (https.createServer)
  - Приложение станет доступно по https://5.189.243.15:8443/
Альтернатива:
  - Использовать USB-сканер (работает по HTTP)
  - Или сканирование через мобильное приложение
