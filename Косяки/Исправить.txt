Что делать дальше
Поскольку вы пересоздаёте базу, миграция не нужна. Но порядок действий:

Остановить сервер:

powershell
pm2 stop pipette
Удалить БД (в MariaDB):

sql
DROP DATABASE pipette;
CREATE DATABASE pipette CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
Запустить сервер — CREATE TABLE IF NOT EXISTS создаст все таблицы со всеми колонками, включая replaced_by / replacing:

powershell
pm2 start pipette
pm2 logs pipette --lines 30
В логах увидите:

text
✅ MySQL подключён
✅ Схема БД готова
🔑 Разовый пароль администратора: admin / XyZ1234abcd
🚀 Server on http://0.0.0.0:3000
Войти под admin с новым паролем, сменить пароль.

Настройки → Система — колонка «Место поверки» появилась, типы заполнены дефолтными значениями:

Пипетка → 📦 Внешняя

Анализатор → 📦 Внешняя

Термометр → 🏠 На месте

Весы → 🏠 На месте

Фотометр → 🏠 На месте

Микроскоп → 🏠 На месте

Всё. После этого можно тестировать полный сценарий.
