.1 — баг «дёргание» воспроизведён
Что видим
text
ДО:    500 x 441.52
ПОСЛЕ: 500 x 517.28     ← выросло на 76 px!
Изменился размер: true
Окно логина резко увеличилось после появления ошибки «Неверный логин или пароль». Именно это ты описывал: «уменьшается, потом увеличивается обратно всё окно вместе с фоновой картинкой».

Хорошее
После ошибки кнопка вернулась в «Войти» ✅

Поля активны ✅

Сообщение показано: «Неверный логин или пароль» ✅

Плохое
Размер формы скачет (+76 px) — визуальный дефект, ради которого и затевали этот тест.

Причина — в frontend/style.css
css
.auth-error { 
  color: #b91c1c;
  font-size: .95rem;
  ...
  min-height: 0;      /* ← ничего не резервирует */
}

.auth-error:empty {
  display: none;      /* ← при пустом тексте скрыт — высота 0 */
}
Когда ошибка появляется:

display: none → display: block — элемент резко прыгает в layout.

.auth-box (с background-image и background-size: cover) растёт → картинка пересчитывается — визуальный «скачок».

Фикс — 2 правки в style.css
Правка 1. Зарезервировать место под ошибку
Найди:

css
.auth-error { 
  color: #b91c1c;                    
  font-size: .95rem;                  
  font-weight: 700;                  
  text-align: center; 
  margin-top: 12px;
  padding: 10px 14px;                 
  background: rgba(255, 255, 255, 0.95); 
  border: 2px solid #dc2626;          
  border-radius: 10px;               
  box-shadow: 0 4px 12px rgba(220, 38, 38, 0.25);
  line-height: 1.4;
  min-height: 0;                      
}

.auth-error:empty {
  display: none;
}
Замени на:

css
.auth-error { 
  color: #b91c1c;                    
  font-size: .95rem;                  
  font-weight: 700;                  
  text-align: center; 
  margin-top: 12px;
  padding: 10px 14px;                 
  background: rgba(255, 255, 255, 0.95); 
  border: 2px solid #dc2626;          
  border-radius: 10px;               
  box-shadow: 0 4px 12px rgba(220, 38, 38, 0.25);
  line-height: 1.4;

  /* 🆕 Резервируем высоту под одну строку — бокс больше не прыгает */
  min-height: 60px;
  box-sizing: border-box;

  /* 🆕 Скрываем через visibility, а не display — место сохраняется */
  visibility: hidden;
  opacity: 0;
  transition: opacity .2s;
}

.auth-error:not(:empty) {
  visibility: visible;
  opacity: 1;
}
Правка 2. Зафиксировать высоту .auth-box
Найди:

css
.auth-box {
  position: relative;
  border-radius: 20px;
  max-width: 500px;
  width: 100%;
  overflow: hidden;
  box-shadow: 0 25px 70px rgba(0, 0, 0, 0.35);
  background-image: url('images/login-bg.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  image-rendering: -webkit-optimize-contrast;
  image-rendering: crisp-edges;
}
Добавь в конце блока одну строку:

css
  min-height: 540px;   /* 🆕 фиксируем минимум — не даём прыгать при появлении ошибки */
Почему именно так
visibility: hidden вместо display: none — элемент остаётся в потоке, резервирует 60 px. Сообщение появится поверх этой зоны, форма не «прыгнет».

min-height: 60px у .auth-error — гарантированно одна строка текста с padding. Если ошибка будет в две строки — бокс подрастёт незначительно, но не на 76 px.

min-height: 540px у .auth-box — страховка. Даже если что-то сработает не так, окно не будет менять высоту.

Проверка после фикса
F5 (или Ctrl+F5).

Выйти из системы.

Замерить «до»:

js
const r = document.querySelector('.auth-box').getBoundingClientRect();
console.log('ДО:', r.width, 'x', r.height);
window.__before = r.height;
Ввести неверный пароль → Войти.

Замерить «после»:

js
const r = document.querySelector('.auth-box').getBoundingClientRect();
console.log('ПОСЛЕ:', r.width, 'x', r.height);
console.log('Дельта:', r.height - window.__before);
Ожидаемо: Дельта: 0.

Про спиннер (проверить заново)
Твой скрипт запускался после запроса (запрос 401 уже прошёл). Поэтому состояние было уже «после», а не «во время».

Правильный способ:

Открой F12 → Console.

Скопируй этот код и нажми Enter (он встанет «в очередь» каждые 200 мс):

js
window.__log = setInterval(() => {
  const btn = document.getElementById('login-btn');
  const btnText = document.getElementById('login-btn-text');
  const btnIcon = document.getElementById('login-btn-icon');
  console.log('[t]', btn.disabled, '|', btnText.textContent, '|', btnIcon.className);
}, 200);
Сразу нажми Войти с неверным паролем.

Через 2 сек останови:

js
clearInterval(window.__log);
Ожидаемо в логе:

text
[t] false | Войти | fa-solid fa-right-to-bracket
[t] true  | Вход…  | fa-solid fa-spinner fa-spin      ← во время запроса
[t] true  | Вход…  | fa-solid fa-spinner fa-spin
[t] false | Войти  | fa-solid fa-right-to-bracket     ← после ошибки
Если так — спиннер работает ✅
